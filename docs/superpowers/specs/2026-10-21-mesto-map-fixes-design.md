# Mesto map fixes - design

Fix visual design flaws in mission 1 (`mesto`) found in a map review: art that stops short of the ceiling, broken pipe columns, floating girders, invisible walls with no visible reason, sealed hollow rooms. The original map (dev overlay, key `o` on `game.html`) is the reference for every fix that has an original counterpart.

## Goals

- Every structure that should meet the ceiling meets it.
- Every blocker the hero can touch has visible art.
- No floating girder ends, no hollow sealed rooms, no one-cell poles into the sky.
- Gameplay stays as it is: same walkable floors, same reach, same tasks.

## Non-goals

- Item list entries the user marked fine: acid guard and shoot guard blocker height, lift 82 column top, street colonnade gap, dressing over walls or lift shafts.
- The roof plank row 10 (kept as is).
- Missions 2-4.

## Constraints

- Assets change in the spike first (`spikes/shared/env-*.js`), then re-port to `src/game/env/` (CLAUDE.md rule). `npm run test:visual` compares them.
- `config/levels/mesto/map.json` is generated by `docs/research/tools/levelmap.py`; change its mesto config (`sky`, `borderFills`, `patches`), never the JSON by hand.
- `reach.test.ts` `GATED.mesto` must still pass. A filled pocket shortens the floor run under it, so its run id (`row,col` of its first cell) may move: rename such ids in `byTask` or `never` (e.g. `30,24`, `44,72`), and drop `never` runs the fixes remove. Before filling a pocket, confirm in game (`moveto`, jumps) that the hero cannot enter it; if he can, keep it open and draw the tower over it with `bare` cells instead.
- No original game names or files in anything the build ships.

## Fixes

Coordinates are world.json cells; `moveto(x,y)` finds each spot (y = floor row).

1. **Switchboard pillar** `moveto(68,70)`: the pillar reaches the metro ceiling (row 66). The prop passes `art.top` (4) and the `switchboard` asset grows its pillar to `size.top`.
2. **Pipe columns through the roof** `moveto(97,10)`: each roof column (y10 at 95.2, 99.7, 111.7, 116.7) and the column under it (y16 at 94.4, 98.9, 111.9, 116.9) become one continuous column: one `pipeColumn` per pair, at the lower column x, from floor 16 up to the old roof column top (row 3), passing behind the roof floor. `pipeColumn` reads `size.h` (scenery `h`); its rings spread over the height. No base stub shows above the roof.
3. **Girder 77.5,41** `moveto(80,44)`: its right end no longer floats. Like the original, the truss runs on to the building east of it (colonnade at 88,44), or ends on a brick pillar; builder's call which looks right.
4. **Plasma barrier** `moveto(100,44)`: the art fills the blocker (rows 38-43): the floor flames, the same flames mirrored hanging from the top emitter, and a wall from that emitter up to the ceiling. Prop `art.top` 6; `plasmaBarrier` reads `size.top`.
5. **Card door** `moveto(47,23)`: a visible wall fills the space above the door up to the ceiling (blocker rows 17-22). Prop `art.top` 6; `cardDoor` reads `size.top`.
6. **Girders like the original**:
