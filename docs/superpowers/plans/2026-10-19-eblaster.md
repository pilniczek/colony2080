# E-Blaster Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The sandbox hero can pick up the E-Blaster, select it with key 3 and fire a continuous lightning beam that pierces every enemy on its floor in sight range; the HUD shows it in slot 3.

**Architecture:** The beam look (zigzag, 6 flicker shapes, jitter) is designed in a new spike shared script and ported 1:1 to TypeScript under the `test:visual` pixel check. The hero gets a third weapon `blaster` that reuses the gun clips and carry pose and emits `beam` events on fixed 32 Hz ticks; `shots.ts` turns each event into damage, sparks and the drawn beam extent. A new `weapon` prop kind gives the E-Blaster.

**Tech Stack:** TypeScript, Vite, Vitest, Playwright visual check, Canvas 2D, inline SVG HUD.

**Spec:** `docs/superpowers/specs/2026-10-19-eblaster-design.md` (research: `docs/research/reports/12-eblaster.md`).

## Global Constraints

- No code comments. `src/engine/**` may not import React, Zustand, `game/` or `sandbox/`. Tuning values in `config/`.
- Record / replay stays deterministic: beam flicker and jitter use game time and a seeded random source, never `Math.random`.
- Every weapon range is `sightCells` (`config/hero/movement.json`); no separate beam range value.
- The published site never references the original game: original references in spikes only through `spikes/shared/originals.js` or `<!-- originals -->` blocks; `npm run build` must pass its leak check.
- Spikes are the design source; ported code must match at 0 pixel diff in `npm run test:visual`.
- `git add` explicit paths only, never `git commit -a`; commit messages plain, no co-author line.
- Docs plain short English, no em dash, each idea once.

## Review Focus

- E-Blaster ammo reaches 0 while the beam is on: the beam stops that tick and the weapon switches to the gun (or fists when the gun is empty). Pinned in Task 3.
- An enemy dies under the beam: it takes no more damage or sparks, and the beam keeps hitting the enemies behind it. Pinned in Task 4.
- The hero hides while firing: the beam stops at once and no `beam` event fires while hidden. Pinned in Task 3.
- A wall between the muzzle and an enemy: the beam ends at the wall and the enemy behind takes nothing. Pinned in Task 4.
- Death after pickup: the hero keeps the E-Blaster and its ammo, and the pickup stays hidden after the map reset. Pinned in Task 5.
