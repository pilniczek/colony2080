# Saves Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Esc pause menu with 5 save slots in `localStorage`, and a GAME OVER screen after death that loads the last save of the mission, restarts it, or ends.

**Architecture:** The menu, slot list and game-over look are designed in `spikes/hud-design/` first (user review stop), then ported to SVG string builders in `src/game/hud/` like the inventory screen. A pure snapshot module turns the world and hero into JSON and back; a slots module stores them through a guarded storage. `startRun` gets a `saves` option (`game.html` only) that wires Esc, the menu keys, game over and loading.

**Tech Stack:** TypeScript, React (overlay only), Zustand store, Vitest, classic-script spike.

**Spec:** `docs/superpowers/specs/2026-10-20-saves-design.md`

## Global Constraints

- Spike first, then port with the same layout; change both together.
- No original-game names or Czech text in visible text; game-over text is `GAME OVER`.
- Slot names: prefix `City - ` plus typed text; 5 slots `A`-`E`.
- `localStorage` access never throws to the caller.
- `SAVE_VERSION` plus prop, lift and enemy counts must match on load, else the message `This save does not fit this version of the mission.`
- Sandbox keeps automatic respawn and has no save menu.
- No code comments; docs and commits in caveman lite; no agent co-author line.
- After each task `npm test`, `npm run lint`, `npm run typecheck` pass.

## Review Focus

- Storage full or blocked (private mode): save shows `Save failed.`, the game continues (Task 3 test).
- A save from an older mission config (counts differ): load refused with the message, world untouched (Task 2 test).
- Typing a slot name: game keys (arrows, X, Ctrl) do not move the hero, Backspace edits, Esc cancels (Task 4 test).
- Esc while inventory, map or a cutscene is active: no menu (Task 5 browser check).
- Death with a save of another mission only: GAME OVER offers Restart mission, not Load (Task 3 test for `latestFor`, Task 5 browser check).
